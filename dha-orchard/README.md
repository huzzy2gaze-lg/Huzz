# DHA Margalla Orchard: knowledge base

A learning and sales kit for DHA Margalla Orchard (FGEHA Phase X, the Park Road Housing Scheme), Islamabad. Researched 4 Nov 2026.

**Start here:** [TRAINING-MANUAL.md](TRAINING-MANUAL.md). It has 11 modules, from project basics to a self-test. `playbook.html` is the same material as an interactive page with a checklist and a quiz.

## Dataset (`data/`)

| File | What it holds |
|---|---|
| `blocks.csv` | Every block (A–H and Commercial): plot count, sizes, terrain, land and allotment notes, our focus |
| `plot_sizes.csv` | 1 Kanal, 14 Marla, 10 Marla and commercial sizes: dimensions, sq ft/sq yd, FGEHA vs SCBA quota, fees |
| `allotment_categories.csv` | The three allotment types (FGEHA, SCBA, land sharing): who, how, papers, checks |
| `land_sharing.csv` | Land by mauza, the land-sharing formulas (SCBA 1 plot per kanal; FGEHA 1:4 then 1:3), land provider, warnings |
| `listings_sample_oct2026.csv` | Live asking prices by block (late Oct 2026). Keep adding to it |
| `transfer_costs.csv` | FGEHA fee table and dealer quotes |
| `timeline.csv` | 2015 to 2027 key events |
| `sources.csv` | Every source with a trust rating |
| `our_holdings.csv` | Our stock by block (about 30 in B, 30 in C, A coming) |
| `field_notes_nadeem.csv` | Mr. Nadeem's answers (4 Nov 2026) and what is still to confirm |
| `inventory_template.csv` | Blank sheet for tracking our own files plot by plot |

All CSVs open in Excel or Google Sheets.

- `Margalla-Orchard-Offer-editable.html`: open in Chrome, click the contact card, type your details, then Ctrl+P (Cmd+P) and Save as PDF.
