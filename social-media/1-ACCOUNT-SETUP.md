# Account setup, step by step

Do the steps in this order. The order matters: the Meta business account must own the Facebook Page, Instagram and the
ad account, so that the company, not one person, owns them.

**Time needed:** about 3 hours in total. Have ready: the company phone (+92 331 5223726) for codes, a company e-mail,
a bank card that allows international online payments, and the images in `brand-kit/`.

**Rules for every account:**
- Use a **company e-mail** (the Zoho address when it works), not one person's personal Gmail.
- Turn on **two-factor login** (an app such as Google Authenticator, not only SMS).
- Have **at least 2 admins** (for example, you and one partner). If one person leaves or loses a phone, the company
  keeps the account.
- Write every login in a password manager (Bitwarden or 1Password), not in WhatsApp chats.

---

## Step 1: WhatsApp Business (15 minutes)
WhatsApp is where most Pakistani buyers will talk to you. Set it up first, because the Facebook and Instagram buttons
link to it.
1. Install **WhatsApp Business** on the company phone (+92 331 5223726). If the number already uses normal WhatsApp,
   WhatsApp Business moves the chats over.
2. Profile: photo = `brand-kit/profile.png`; name = `WH Ventures`; category = Real Estate; description = the Facebook
   bio in `2-PROFILE-TEXT.md`; website = the WhatsApp link in `utm-links.csv`.
3. Tools → **Greeting message**: "Assalam o Alaikum! Thank you for contacting WH Ventures. Which plot size are you
   looking for: 1 Kanal, 14 Marla or 10 Marla? Our team will reply shortly."
4. Tools → **Away message** outside office hours, and **Quick replies** for prices, location and documents.
5. Tools → **Labels**: New lead, Called, Site visit, Token, Closed. (The sales system keeps the real records; the labels
   only help in the chat list.)

## Step 2: Meta business account (Facebook + Instagram + ads) (45 minutes)
1. On a computer, go to **business.facebook.com** → Create an account. Business name: `WH Ventures (Pvt.) Ltd.`, your
   name, and the company e-mail. (You need a personal Facebook profile to log in; it stays private. Use a real profile
   with your real name: Meta closes fake profiles, and everything they own goes with them.)
2. **Create the Facebook Page:** Business settings → Accounts → Pages → Add → Create a new Page.
   - Name, category, bio and About: from `2-PROFILE-TEXT.md`.
   - Profile picture: `brand-kit/profile.png`. Cover: `brand-kit/facebook-cover.png`.
   - Username: `whventurespk`.
   - Add the WhatsApp button: Page → Edit action button → WhatsApp → +92 331 5223726.
3. **Create Instagram:** in the Instagram app → Create new account → `whventurespk` → then Settings → Account type →
   **Switch to professional account → Business** → category Real Estate Agent.
   - Profile picture `brand-kit/profile.png`, bio from `2-PROFILE-TEXT.md`, link from `utm-links.csv`.
   - Settings → **Account Center** → connect it to the Facebook Page.
   - In Business settings → Accounts → Instagram accounts → add it, so the business owns it.
4. **Highlights:** post one story for each topic, add it to a highlight, and use the covers in
   `brand-kit/instagram-highlights/`.
5. **Ad account:** Business settings → Accounts → Ad accounts → Add → Create a new ad account.
   - Name: `WH Ventures - Main`, time zone **Asia/Karachi**, currency **PKR**. (You cannot change these later.)
   - Add the payment card (Billing → Payment settings). Ask your bank to allow **international e-commerce** on the
     card. Banks in Pakistan may add tax on these payments; check your statement after the first charge.
6. **Add people:** Business settings → Users → People → invite the second admin with full control. Give agents only
   "Page: messages" access, if they need to answer chats.
7. **Verify the business** later (Business settings → Security Center → Verification). It needs company documents
   (SECP certificate, utility bill). Verified businesses get fewer ad blocks.
8. **Pixel (website tracking):** Events Manager → Connect data → Web → name `WH Ventures website` → copy the
   **Pixel ID** and send it to the website session (see `WEBSITE-HANDOFF.md`). Without the pixel, Meta cannot learn
   who books calls, and ads cost more.

## Step 3: TikTok (20 minutes)
1. Install TikTok → Sign up with the company e-mail → handle `whventurespk`.
2. Profile picture `brand-kit/profile.png`, name `WH Ventures`, bio from `2-PROFILE-TEXT.md`.
3. Settings → Account → **Switch to Business account** → category Real Estate.
4. Add the website link (TikTok link from `utm-links.csv`) when the field appears.
5. For ads later: **ads.tiktok.com** → create an ad account in PKR, Asia/Karachi. The in-app **Promote** button is
   enough for our small budget (see `3-AD-PLAN.md`).

## Step 4: YouTube (20 minutes)
1. Use a **Google account for the company** (the same one you will use for Google Business and Google Ads). If Zoho
   is the e-mail, create the Google account with the Zoho address ("Use my current e-mail address instead").
2. youtube.com → profile icon → **Create a channel** → name `WH Ventures | DHA Margalla Orchard`, handle `@whventurespk`.
3. Customise channel → Branding: picture `brand-kit/profile.png`, banner `brand-kit/youtube-banner.png`.
   Basic info: the description and links from `2-PROFILE-TEXT.md`, contact e-mail.
4. Settings → Permissions → invite the second admin as **Manager**.
5. Verify the phone number (Settings → Channel → Feature eligibility), so you can add custom thumbnails and longer
   videos.

## Step 5: Google Business Profile (20 minutes, then verification)
1. Go to **business.google.com** with the company Google account → Add business → `WH Ventures`.
2. Category, address or service area, phone, website, description: from `2-PROFILE-TEXT.md`.
3. **Verification:** Google asks for a short video of the office, the signboard and proof of the business (or a code
   by post). Plan this; it can take from a few days to two weeks.
4. Add photos: logo `brand-kit/profile.png`, cover `brand-kit/google-business-cover.png`, and real photos.
5. After each closed deal, ask the happy client for a Google review. Reviews bring the most trust for real estate.

## Step 6: LinkedIn (15 minutes)
1. Log in with your personal LinkedIn → **For Business → Create a Company Page → Company**.
2. Name `WH Ventures (Pvt.) Ltd.`, URL `linkedin.com/company/whventurespk`, website, industry Real Estate, size 2–10.
3. Logo `brand-kit/profile.png`, cover `brand-kit/linkedin-cover.png`, tagline and About from `2-PROFILE-TEXT.md`.
4. Add the team: each person adds "WH Ventures" as their current job, so the page shows real people.

## Step 7: Link everything together (10 minutes)
- Each profile's website link: the matching link in `utm-links.csv`.
- On the website footer: links to all the profiles (send the handles to the website session).
- Post the same welcome post on every platform on the same day (day 1 of `4-CONTENT-CALENDAR.md`).
